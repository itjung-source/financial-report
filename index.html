เข้าสู่ระบบเป็น  ·  ออกจากระบบ

หมายเหตุ: F45 = ข้อมูลเบื้องต้นจากข่าว F45 (มีแค่กำไรสุทธิ/EPS ยังไม่มีรายได้/GPM เต็ม)  |  QoQ%/YoY% ของตารางล่าง คือของกำไรสุทธิ, QoQ%/YoY% ของตาราง EPS ด้านบน คือของ EPS  |  กราฟบนสุดเลือกได้ว่าจะเทียบราคาหุ้นกับ EPS สะสม 4 ไตรมาส (TTM) หรือกับดัชนี SET — ดัชนี SET ย้อนหลังได้ถึงไตรมาส 3/2564 เท่านั้น (SET API ให้ย้อนได้สูงสุด 5 ปี) ไตรมาสก่อนหน้านั้นเส้นจะว่าง
โหมดรายปี: รายได้/กำไรขั้นต้น/SG&A/กำไรสุทธิ/EPS = ผลรวมทั้งปี จะแสดงก็ต่อเมื่อมีค่าครบทุกไตรมาส ถ้าขาดไตรมาสใดจะขึ้น — แทน (กันยอดรวมไม่ครบแต่ดูเหมือนครบ), GPM%/NPM% คิดใหม่จากยอดรวม, ส่วน P/E, P/BV, ROE% เป็นค่า ณ ไตรมาสท้ายสุดของปีนั้น (ไม่ใช่ค่าเฉลี่ย)  |  YoY% รายปีจะแสดงเฉพาะเมื่อทั้งสองปีมีจำนวนไตรมาสเท่ากัน ปีที่ยังไม่ครบจะวงเล็บบอกไว้
